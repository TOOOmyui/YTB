      Connexion au dépôt GitHub

      Créer le jeton (2 minutes)
      1. Ouvre GitHub → Fine-grained token ↗.
      2. Repository access : Only select repositories → le dépôt de la régie.
      3. Permissions du dépôt : Contents lecture et écriture, Actions lecture et écriture, Secrets lecture (pour vérifier la configuration).
      4. Génère, copie, colle ici. Le jeton reste dans ce navigateur : il n'est envoyé qu'à api.github.com.

      Sans jeton, la page fonctionne en lecture seule (données publiques, rafraîchies toutes les 5 minutes environ).
